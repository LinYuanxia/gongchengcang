## 一、功能概述

### 1.1 功能定位

工程仓配置是供应商端的**供货关系管理模块**，用于配置供应商与工程仓之间的供货关联关系，包括设置哪些供应商可以向哪些工程仓供货，以及对应的配送、佣金等配置信息。

### 1.2 核心概念

| 概念 | 说明 |
|:----|------|
| 工程仓 | 采购方（工程方）在平台创建的仓库，代表具体的工程项目 |
| 供应商工程仓配置 | 供应商与工程仓之间的供货关系定义，配置后供应商可向该工程仓供货 |
| 按供应商查看 | 以供应商为维度查看其已配置的工程仓列表 |
| 按工程仓查看 | 以工程仓为维度查看其已关联的供应商列表 |

### 1.3 目标用户

- **管理员**：管理供应商与工程仓的供货关系配置
- **业务员**：查看供应商与工程仓的配置关系

### 1.4 模块范围

| 功能点 | 说明 | 优先级 |
|:------|------|:------:|
| 双视图切换 | 按供应商/按工程仓两种查看维度 | P1 |
| 搜索筛选 | 按关键词/配置状态搜索过滤 | P1 |
| 添加配置 | 3步向导：选供应商→选工程仓→配置信息 | P1 |
| 查看关联 | 查看供应商的工程仓列表或工程仓的供应商列表 | P1 |
| 编辑配置 | 修改已有的供货配置信息 | P2 |

## 二、核心设计原则

> **工程仓配置遵循"批量和批量"原则——支持一次选择多个供应商和多个工程仓建立关联。**

### 2.1 批量配置原则

- 一次配置操作可选择多个供应商和多个工程仓
- 供应商选择页和工程仓选择页均支持全选/多选
- 所选供应商与所选工程仓建立多对多的供货关系

### 2.2 独立配置原则

- 配置信息（配送方式、结算周期等）与供应商-工程仓关系绑定
- 同一供应商在不同工程仓的配置可以不同
- 同一工程仓对接不同供应商的配置也可以不同

## 三、功能点详细设计

### 3.1 页面布局

页面分为两种视图模式，通过 RadioGroup 按钮切换：

**按供应商查看视图**：
- 搜索栏：关键词搜索（供应商名称）+ 配置状态筛选（已配置/未配置）
- 表格列：供应商ID、供应商名称、联系人、联系电话、已配置工程仓数（可点击查看）、供货商品数、状态Tag、操作（查看工程仓/配置）

**按工程仓查看视图**：
- 搜索栏：关键词搜索（工程仓名称）+ 配置状态筛选（已配置/未配置）
- 表格列：工程仓ID、工程仓名称、联系人、联系电话、地址、已配置供应商数（可点击查看）、状态Tag、操作（查看供应商/配置）

### 3.2 添加配置（3步向导）

#### 第1步：选择供应商

- 搜索框：按供应商名称或ID搜索
- 列表区：供应商ID、供应商名称、联系人、联系电话
- 支持Checkbox多选/全选
- 显示已选择数量 → "下一步"按钮

#### 第2步：选择工程仓

- 搜索框：按工程仓名称或ID搜索
- 列表区：工程仓ID、工程仓名称、联系人、联系电话
- 支持Checkbox多选/全选
- 显示已选择数量 → "上一步"/"下一步"按钮

#### 第3步：配置信息

| 配置项 | 说明 |
|:------|:------|
| 配送方式 | 可选配送模式 |
| 结算周期 | 月结/周结/日结 |
| 佣金比例 | 百分比设置 |
| 备注 | 文本备注 |

提交成功后，所选供应商与工程仓的关联关系建立。

### 3.3 查看关联

- 点击"已配置工程仓数"或"查看工程仓" → 展示该供应商关联的所有工程仓列表
- 点击"已配置供应商数"或"查看供应商" → 展示该工程仓关联的所有供应商列表

### 3.4 编辑配置

- 点击已有配置的"配置"或"编辑"按钮 → 弹出配置编辑Modal
- 可修改配送方式、结算周期、佣金比例等配置信息
