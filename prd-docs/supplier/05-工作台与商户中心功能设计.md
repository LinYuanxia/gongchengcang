## 一、功能概述

### 1.1 功能定位

工作台与商户中心是供应商端的**核心入口和信息管理模块**，工作台提供运营指标概览和日常待处理的快捷入口，商户中心管理供应商的企业档案、资质证照和合同信息。

### 1.2 核心概念

| 概念 | 说明 | 示例 |
|:----|------|------|
| 工作台 | 供应商登录后的首页，展示数据概览和待办事项 | 4个核心指标卡片 |
| 商户信息 | 供应商的企业工商信息、资质证照、结算账户等档案 | 营业执照、信用代码等 |
| 合同管理 | 供应商与平台签订的合作协议管理 | 年度供货合同 |
| 资质管理 | 供应商上传和维护的企业资质证照 | 营业执照、安全生产许可证 |

### 1.3 目标用户

- **管理员**（核心用户）：查看运营概览、管理企业信息、合同、资质
- **业务员**：查看工作台数据概览和合同
- **财务**：查看工作台数据概览

### 1.4 模块范围

| 功能页面 | 主要功能 | 优先级 |
|:--------|---------|:------:|
| 工作台 | 指标卡片、待处理事项、快捷入口、平台公告 | P1 |
| 商户信息 | 基础信息查看、主体信息查看、结算账户查看 | P1 |
| 资质管理 | 资质列表、新增资质、查看附件、删除资质 | P1 |
| 合同管理 | 合同列表查看、搜索筛选、合同详情、合同下载 | P1 |

## 二、核心设计原则

> **工作台遵循"轻量概览"原则，商户中心遵循"只读展示"原则。**

### 2.1 指标轻量化原则

- 工作台只展示4个关键运营指标，不做明细数据下钻
- 各指标卡片独立展示，互不影响
- 固定展示全量数据，不支持时间范围切换

### 2.2 只读展示原则

- 商户信息所有字段（基础信息/主体信息/结算账户）均为**只读展示**，不支持编辑
- 资质的增删操作为独立入口，不影响其他信息的只读性
- 合同信息以嵌入表格形式展示在profile页面，详情跳转到独立合同管理页

## 三、业务规则

### 3.1 数据概览规则

- **供货中商品**：当前处于"供货中"状态的SKU数量
- **待处理订单**：待接单+待发货状态的订单总数
- **本月供货额**：当前自然月已发货订单的总金额
- **累计结算金额**：历史所有已结算订单的总金额
- 空数据展示：加载失败时卡片显示"--"

### 3.2 待处理事项规则

- 事项列表展示3条最紧急的待处理业务
- 点击"立即处理"跳转到对应的业务页面
- 点击"查看全部"跳转到对应模块列表页

## 六、功能点详细设计

### 6.1 工作台（P1）

#### 页面布局

页面分为4个区域，从上到下排列：
1. **欢迎横幅**：渐变蓝色背景，显示"欢迎进入材料供应商平台"标题和"工程材料管理采供一体化平台"副标题
2. **指标卡片行**：4个卡片横向排列（供货中商品/待处理订单/本月供货额/累计结算金额）
3. **内容区**：左侧2/3宽度为"待处理事项"列表，右侧1/3宽度分为"快捷入口"和"平台公告"
4. **快捷入口**：3个图标链接（商品管理/主体信息/合同列表）

#### 指标卡片定义

| 字段 | 说明 | 展示规则 |
|:----|------|:--------|
| 供货中商品 | 当前在售SKU数量 | 整数字体加粗，带绿色图标 |
| 待处理订单 | 待接单+待发货订单数 | 整数字体加粗，带黄色图标 |
| 本月供货额 | 当月已发货总金额 | 金额格式 ¥xxx,xxx.xx，带货币前缀 |
| 累计结算金额 | 历史已结算总金额 | 金额格式 ¥xxx,xxx.xx，带货币前缀 |

#### 待处理事项

展示3条待办事项，每条包含：
- 标题：事项简述（如"有3个新订单待确认"）
- 描述：事项详细说明
- 图标：根据类型显示不同颜色图标（告警/提示/信息）
- 操作按钮："立即处理"链接，点击跳转到对应业务页面

#### 平台公告

展示4条平台公告列表，每条显示标题和发布日期。

### 6.3 合同管理（P1，独立页面）

#### 交互逻辑

1. 页面加载：展示合同列表，支持分页
2. 搜索：按合同编号/合同名称模糊搜索
3. 筛选：合同状态下拉（生效中/已过期/待生效）
4. 新增：点击"新增合同"按钮（当前为占位功能）
5. 查看：点击"查看"按钮 → 弹出合同详情Modal
6. 下载：点击"下载" → 下载合同附件文件

#### 页面字段

| 字段 | 必填 | 来源 | 展示规则 |
|:----|:----|:----:|:--------|
| 合同编号 | 是 | 系统 | 文本 |
| 合同名称 | 是 | 系统 | 文本 |
| 合同类型 | 是 | 系统 | Tag标签：供货合同(蓝)/采购合同(绿)/服务合同(橙) |
| 签订日期 | 是 | 系统 | YYYY-MM-DD |
| 生效日期 | 是 | 系统 | YYYY-MM-DD |
| 到期日期 | 是 | 系统 | YYYY-MM-DD |
| 合同状态 | 是 | 系统 | Tag标签：生效中(绿)/已过期(红)/待生效(橙) |
| 操作 | - | - | 查看/下载 |

#### 合同详情Modal

展示完整的合同信息：合同编号/名称/类型/状态/签订日期/生效日期/到期日期/合同金额/甲方/乙方/合同附件（下载链接）/备注。
