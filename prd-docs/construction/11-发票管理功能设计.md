## 一、功能概述

### 1.1 功能定位

发票管理是工程仓端**向平台申请发票和查看已收发票的核心入口**，承担两大职责：

| 职责 | 说明 |
|:----|:-----|
| **发票申请** | 工程仓基于撮合服务费结算单向平台申请开具增值税发票 |
| **发票接收** | 查看平台已开具并交付的发票，下载发票文件（PDF/图片） |

工程仓端的发票管理以「申请→追踪→接收」为主链路，平台负责审核和开票（线下开票）。

### 1.2 核心概念

| 概念 | 定义 |
|:----|:-----|
| **销项发票** | 平台向工程仓开具的发票，工程仓作为收票方（买方），用于成本入账 |
| **撮合服务费发票** | 平台就撮合服务费向工程仓开具的发票，是最常见的开票类型 |
| **发票申请** | 工程仓在系统中发起开票请求，平台财务线下开票后录入系统 |
| **已开票状态** | 平台财务已开具并录入发票，发票文件可在工程仓端查看/下载 |
| **红字发票** | 发生退款时，平台开具的负数发票冲抵原发票 |

### 1.3 目标用户

| 用户角色 | 使用场景 | 使用频率 |
|---------|---------|:--------:|
| 工程仓财务 | 申请发票、查看发票状态、下载发票文件 | 中频（按需） |
| 工程仓采购 | 了解订单对应的发票情况 | 低频（查询） |
| 工程仓管理员 | 审批开票申请、查看发票统计 | 低频（管理） |

### 1.4 模块范围

| 功能分类 | 主要功能 | 优先级 |
|---------|---------|:------:|
| 发票申请 | 发起开票申请、选择结算单关联 | P1 |
| 我申请的发票 | 发票申请列表、申请详情、进度追踪 | P1 |
| 我收到的发票 | 已开具发票列表、发票文件预览、下载 | P1 |
| 发票详情 | 发票完整信息展示、关联订单 | P1 |

### 1.5 四端边界（工程仓视角）

| 能力维度 | 平台端 | 供应商端 | 工程仓端 |
|---------|:------:|:--------:|:--------:|
| 发票申请审核 | ✅ 审核工程仓申请 | ❌ | ❌ |
| 发票开具录入 | ✅ 线下开票后录入 | ❌ | ❌ |
| 发起开票申请 | ❌ | ❌ | ✅ 是 |
| 查看已开票文件 | ✅ 全量 | ❌ | ✅ 仅自己 |
| 发票配置维护 | ✅ 是 | ❌ | ❌ |
| 发起进项发票 | ❌ | ✅ 是 | ❌ |

## 二、核心设计原则

### 2.1 申请管控机制

| 审核场景 | 审核对象 | 审核角色 | 说明 |
|---------|---------|:--------:|:-----|
| 开票申请 | 工程仓提交的开票申请 | 平台财务 | 基于结算单审核开票金额是否合理 |
| 发票作废/红冲 | 平台已开具发票 | 平台财务 | 需工程仓配合提供原因 |

### 2.2 核心设计原则（"三不三做"）

| 原则 | 说明 |
|:----|:-----|
| ❌ **不做开票校验** | 未申请发票不影响订单支付、收货等业务流程 |
| ❌ **不做税金计算** | 税金由线下财务核算，系统只做申请存证 |
| ❌ **不做流程拦截** | 未申请/未收到发票不阻塞任何业务操作 |
| ✅ **做申请存证** | 工程仓提交的开票申请完整记录，供平台审核参考 |
| ✅ **做关联追溯** | 发票与撮合费结算单双向可查 |
| ✅ **做状态通知** | 发票开具完成/被驳回时，系统消息及时通知工程仓 |

### 2.3 业务规则

| 规则 | 内容 |
|:----|:-----|
| **申请触发** | 基于平台出具的撮合服务费结算单，工程仓可申请开具发票 |
| **发票类型** | 支持增值税专用发票、增值税普通发票、增值税电子普通发票 |
| **税率说明** | 平台录入发票时确定税率，工程仓申请时可见参考税率范围 |
| **金额约束** | 开票金额不能超过关联结算单的实际未开票金额 |
| **作废/红冲** | 平台已开发票如需作废/红冲，由平台财务操作，工程仓端可见状态变更 |
| **文件格式** | 发票文件支持PDF/图片格式，可在详情页预览和下载 |

## 三、发票申请流程（P1）

### 3.1 功能说明

工程仓基于撮合服务费结算单向平台提交开票申请，平台财务审核后线下开票并录入系统，工程仓端可查看进度并下载发票文件。

### 3.2 入口路径

财务中心 → 发票管理 → 申请开票

### 3.3 页面布局

| 区域 | 内容 | 组件 |
|:----|:-----|:----:|
| PageHeader | 返回 + 申请开票 + 当前申请进度Tag | a-page-header |
| 可开票结算单 | 可申请开票的撮合费结算单列表（仅展示未开票金额>0的结算单） | a-table |
| 已选结算单 | 申请人选择的待开票结算单汇总 | 卡片列表 |
| 开票信息表单 | 填写开票信息和上传资质文件 | a-form |
| 提交按钮 | 确认提交申请 | a-button |

### 3.4 申请流程（Stepper）

```
Step1: 选择结算单 → Step2: 填写开票信息 → Step3: 确认提交
```

### 3.5 Step1 - 选择结算单

**可开票结算单列表**：

| 字段 | 说明 |
|:----|:-----|
| 结算单号 | 平台出具的撮合费结算单编号 |
| 结算金额 | 撮合服务费总额 |
| 已开票金额 | 已在平台申请开票的金额 |
| 未开票金额 | 可申请开票的余额 = 结算金额 - 已开票金额 |
| 账单周期 | 如2026年4月 |
| 出单时间 | 结算单生成日期 |
| 操作 | 选择（checkbox） |

**交互逻辑**：
- 默认展示所有未开票金额 > 0 的撮合费结算单
- 支持多选（合并开票）
- 选择结算单后，已选区域自动更新显示汇总金额
- 点击"下一步"前至少选择一个结算单

### 3.6 Step2 - 填写开票信息

**开票信息表单**：

| 字段 | 组件 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| 发票类型 | a-radio | 是 | 专票 / 普票 / 电子普票 |
| 购买方名称 | a-input | 是 | 工程仓企业名称（自动填充，只读） |
| 购买方税号 | a-input | 是 | 工程仓纳税人识别号（自动填充，只读） |
| 购买方地址电话 | a-input | 是 | 自动填充（注册地址+联系电话） |
| 购买方开户行账号 | a-input | 是 | 自动填充（开户行+账号） |
| 发票送达方式 | a-radio | 是 | 电子发票（发送邮箱）/ 纸质发票（邮寄） |
| 接收邮箱 | a-input | 条件 | 电子发票时必填 |
| 收件人 | a-input | 条件 | 纸质发票时必填 |
| 联系电话 | a-input | 条件 | 纸质发票时必填 |
| 收件地址 | a-input | 条件 | 纸质发票时必填 |
| 备注 | a-textarea | 否 | 如有特殊开票要求可填写 |

> **自动填充说明**：购买方信息自动填充工程仓在平台入驻时填写的企业信息（资质文件），如需修改需前往企业信息页更新。

**已选结算单汇总**（右侧或底部）：

| 信息 | 说明 |
|:----|:-----|
| 已选结算单数 | N个 |
| 结算单总金额 | ¥X,XXX.XX |
| 申请开票总金额 | ¥X,XXX.XX（= 选中的未开票金额合计） |

### 3.7 Step3 - 确认提交

| 确认项 | 说明 |
|:-------|:-----|
| 申请信息预览 | 汇总展示：购买方信息、发票类型、开票金额、结算单列表 |
| 送达方式确认 | 再次确认邮箱/收件地址 |
| 提交条款 | Checkbox：我确认以上开票信息准确，发票开具后不可撤销 |

**提交后**：
- 跳转到"我申请的发票"列表页
- 新申请的发票状态为"申请中"
- 系统消息通知平台财务有新开票申请

### 3.8 申请状态说明

| 状态 | 说明 | 可见角色 |
|:----|:-----|:--------:|
| 申请中 | 工程仓已提交，平台财务待审核 | 工程仓+平台 |
| 已通过 | 平台财务审核通过，等待开票 | 工程仓+平台 |
| 已开票 | 平台已开具发票，工程仓可查看/下载 | 工程仓+平台 |
| 已驳回 | 平台财务驳回申请，工程仓可见驳回原因 | 工程仓+平台 |
| 已作废 | 平台对已开票进行作废处理 | 工程仓+平台 |
| 已红冲 | 平台对已开票进行红冲处理 | 工程仓+平台 |

## 四、发票列表（P1）

### 4.1 功能说明

工程仓端发票管理以双 Tab 结构组织：「我申请的发票」和「我收到的发票」，分别追踪申请进度和查看已开具发票。

### 4.2 入口路径

财务中心 → 发票管理

### 4.3 Tab1 - 我申请的发票

#### 页面布局

| 区域 | 内容 | 组件 |
|:----|:-----|:----:|
| 统计栏 | 申请中数 / 已通过数 / 已开票数 / 已驳回数 | a-statistic × 4 |
| 操作按钮 | 申请开票 | a-button |
| 筛选区 | 结算单号、申请状态、开票类型、申请日期范围 | a-select + a-input + a-range-picker |
| 表格 | 发票申请列表（详见字段定义） | a-table |
| 分页 | 50条/页 | a-pagination |

#### 交互逻辑

1. **默认加载**：最近6个月，按申请时间倒序
2. **申请开票**：点击"申请开票" → 跳转发票申请流程页
3. **点击结算单号**：跳转结算单详情
4. **单行操作**：
   - 申请中状态：查看详情、撤回申请（撤回后需重新申请）
   - 已驳回状态：查看详情、重新申请（跳转申请流程，预填充原信息）
   - 已通过/已开票状态：查看详情
   - 已撤回/已作废/已红冲：仅查看详情

#### 原子字段定义（列表表格）

| 字段 | 类型 | 展示规则 | 排序 |
|:----|:----|:--------|:---:|
| 申请单号 | String(24) | 超链接，点击跳详情 | ✅ |
| 关联结算单 | String(32) | 超链接，跳转结算单详情 | ❌ |
| 发票类型 | Enum | Tag：专票(蓝)/普票(绿)/电子普票(紫) | ❌ |
| 申请开票金额 | Decimal(12,2) | ¥前缀，右对齐 | ✅ |
| 送达方式 | Enum | Tag：电子(蓝)/纸质(橙) | ❌ |
| 申请状态 | Enum | Tag：申请中(橙)/已通过(蓝)/已开票(绿)/已驳回(红)/已撤回(灰)/已作废(灰)/已红冲(紫) | ❌ |
| 驳回原因 | String(100) | 申请状态为"已驳回"时显示原因摘要 | ❌ |
| 申请时间 | DateTime | YYYY-MM-DD HH:mm | ✅ |
| 更新时间 | DateTime | 状态变更时间 | ❌ |
| 操作 | — | 详情/撤回/重新申请（根据状态） | ❌ |

### 4.4 Tab2 - 我收到的发票

#### 页面布局

| 区域 | 内容 | 组件 |
|:----|:-----|:----:|
| 统计栏 | 已收发票数 / 本月收票金额 / 待处理数 | a-statistic × 3 |
| 操作按钮 | 导出Excel | a-button |
| 筛选区 | 发票号码、发票类型、开票日期范围 | a-input + a-range-picker |
| 表格 | 已收发票列表（详见字段定义） | a-table |
| 分页 | 50条/页 | a-pagination |

#### 交互逻辑

1. **默认加载**：最近6个月，按开票日期倒序
2. **点击发票号码**：跳转发票详情页
3. **单行操作**：
   - 已开票：查看详情、下载（下载发票文件）
   - 已作废：查看详情（文件不可下载，标灰）
   - 已红冲：查看详情（显示红冲标识，原始发票文件仍可下载参考）

#### 原子字段定义（列表表格）

| 字段 | 类型 | 展示规则 | 排序 |
|:----|:----|:--------|:---:|
| 发票号码 | String(20) | 超链接，点击跳详情 | ✅ |
| 发票代码 | String(12) | 文本 | ❌ |
| 发票类型 | Enum | Tag：专票(蓝)/普票(绿)/电子普票(紫) | ❌ |
| 开票金额 | Decimal(12,2) | ¥前缀，右对齐 | ✅ |
| 不含税金额 | Decimal(12,2) | ¥前缀 | ❌ |
| 税额 | Decimal(12,2) | ¥前缀 | ❌ |
| 税率 | Decimal(4,2) | 如6% | ❌ |
| 开票日期 | Date | YYYY-MM-DD | ✅ |
| 关联结算单 | String(32) | 超链接 | ❌ |
| 发票状态 | Enum | Tag：已开(绿)/已作废(灰)/已红冲(紫) | ❌ |
| 操作 | — | 详情/下载（根据状态） | ❌ |

## 六、异常处理汇总表

### 6.1 发票申请异常

| 异常场景 | 触发条件 | 前端处理 | 提示文案 |
|:--------|:--------|:--------|:---------|
| 未选择结算单 | 点击"下一步"但未选结算单 | 按钮禁用 + 提示 | "请至少选择一个结算单" |
| 结算单无可开票金额 | 选中的结算单未开票金额=0 | 自动过滤，不允许选择 | "该结算单已无未开票金额" |
| 邮箱格式错误 | 填写非有效邮箱地址 | 前端格式校验 | "请输入有效的邮箱地址" |
| 纸质发票地址缺失 | 选择纸质发票但未填写收件信息 | 前端校验 | "请填写完整的收件地址和联系方式" |
| 申请中无法重复申请 | 对"申请中"状态再次点击"申请开票" | 跳转至申请中详情 | "您有一笔申请正在审核中，请等待处理" |
| 撤回申请失败 | 平台财务已开始审核 | 后端拦截 | "该申请已进入审核流程，无法撤回" |
| 网络错误 | 提交申请接口失败 | Toast + 重试按钮 | "提交失败，请稍后重试" |

### 6.2 发票查看异常

| 异常场景 | 触发条件 | 前端处理 | 提示文案 |
|:--------|:--------|:--------|:---------|
| 发票文件下载失败 | 文件服务器返回错误 | Toast提示 | "下载失败，请稍后重试" |
| 发票已作废 | 对已作废发票点击下载 | 按钮置灰+Tooltip | "该发票已作废，不可下载" |

| 发送邮箱失败 | 邮件发送接口返回错误 | Toast提示 | "邮件发送失败，请检查邮箱地址" |
