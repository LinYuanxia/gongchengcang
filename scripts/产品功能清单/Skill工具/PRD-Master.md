四、图表生成规则（必须遵守）
4.1 业务流程图规则
text
输入：核心入口方法 + 调用链
输出：Mermaid graph TD

强制要求：
- 必须包含至少1个判断节点（菱形）
- 必须包含至少1个异常分支（如失败返回）
- 节点命名清晰，如[工程仓创建订单]
- 使用 --> 连接，分支用 -->|条件| 标注

代码映射：
- 顺序调用 → 顺序节点
- if/switch → 判断节点
- try-catch → 异常分支
- 状态赋值 → 标注状态变化
4.2 泳道图规则
text
输入：不同端Controller + MQ监听器 + 定时任务
输出：Mermaid sequenceDiagram

强制要求：
- 每个端/系统一个participant
- 跨端调用用 ->> 或 -->>
- 异步消息标注（如MQ）
- 定时任务标注为 participant 系统

代码映射：
- @RequestMapping前缀 → participant名称
- MQ发送 → A->>B
- @EventListener → 接收方标注
4.3 状态机图规则
text
输入：枚举定义 + 所有status赋值点
输出：Mermaid stateDiagram-v2

强制要求：
- 每个枚举值一个状态
- 标注所有合法转换
- 使用 --> 标注转换
- 可选标注触发条件如：待接单 --> 已接单: 供应商接单

代码映射：
- 枚举类 → 状态列表
- service中status = 某值 → 转换路径
- 结合if条件 → 触发条件
4.4 ER图规则
text
输入：实体类/JPA注解/DDL
输出：Mermaid erDiagram

强制要求：
- 每个实体一个节点
- 标注主键PK、外键FK
- 标注关系：||--o{ 一对多，||--|| 一对一
- 至少3个核心实体

代码映射：
- @Entity/@Table → 实体节点
- @Id → PK
- @ManyToOne/@OneToMany → 关系
- @JoinColumn → 外键
